DynamicalResilience.DynamicalResilience — Module
DynamicalResilience

Resilience of dynamical systems written as SciML problems: steady states, the basic reproduction number by the next-generation method, period maps and Floquet multipliers of forced systems and of any map, resilience followed along a parameter to a fold or a Hopf bifurcation, and the distribution of resilience metrics over parameter draws.

Results are the operator types of ResilienceCore.jl (ContinuousJacobian, DiscreteJacobian), so every ResilienceCore metric applies to them. No ODE solver is a dependency: functions that integrate take the algorithm as alg.

Steady states

DynamicalResilience.steady_state — Function
steady_state(prob::ODEProblem, u0 = prob.u0; p = prob.p, t = first(prob.tspan),
             method = :newton, alg = nothing, tol = 1e-10, maxiters = 100, tmax = 1e4,
             solve_kwargs...)
    -> (u, converged, residual, iterations)

An equilibrium u of prob (f(u, p, t) = 0), started from u0.

  • method = :newton: damped Newton iteration on f, with the Jacobian from the problem's analytic jac if it has one and by ForwardDiff otherwise, halving the step until the residual falls. It converges to the equilibrium near u0 whether or not that equilibrium is stable, which is what continuation needs (resilience_along).
  • method = :integrate: integrate from u0 over (t, t + tmax) with the ODE algorithm alg (required; for example Tsit5() from OrdinaryDiffEqTsit5), then refine the end state by Newton. It finds an attracting equilibrium, the one a simulation would reach.

converged is true when the residual ‖f(u)‖∞ is at most tol · max(1, ‖u‖∞). solve_kwargs are passed to solve for :integrate.

source
steady_state(prob::DiscreteProblem, u0 = prob.u0; p = prob.p, t = first(prob.tspan),
             method = :newton, tol = 1e-10, maxiters = 100, iterations = 10_000, h = 1e-6)
    -> (u, converged, residual, iterations)

A fixed point u of the discrete-time map of prob (f(u, p, t) = u), started from u0.

  • method = :newton: fixed_point on u ↦ f(u, p, t), which finds the fixed point near u0 whether or not it is stable.
  • method = :iterate: apply the map up to iterations times from u0, then refine by Newton; it finds an attracting fixed point, the one a simulation would reach.

The returned fields match the ODE method; residual is ‖f(u) − u‖∞.

The basic reproduction number

DynamicalResilience.reproduction_number — Function
reproduction_number(prob::ODEProblem, dfe; infected, new_infections, p = prob.p,
                    t = first(prob.tspan), check = true, tol = 1e-8)
    -> (R0, F, V, K)

The basic reproduction number of prob at its disease-free equilibrium dfe, by the next-generation method of van den Driessche & Watmough (2002).

  • infected are the indices of the infected compartments (or, for a macroparasite or pathogen-load model, of every state that carries infection).
  • new_infections(u, p, t) returns the rate at which new infections enter each of them, a vector in the order of infected. Everything else in f restricted to infected (progression, recovery, death, and transfers between infected compartments) is the transition part.

With F = ∂new_infections/∂x and V = F − ∂f_infected/∂x, both over the infected states at dfe and computed by ForwardDiff, K = F V⁻¹ is the next-generation matrix and R0 = ρ(K). The disease-free equilibrium is locally stable when R0 < 1 and unstable when R0 > 1, provided the uninfected subsystem is stable at dfe (the conditions of the theorem). check verifies that dfe is an equilibrium (‖f(dfe)‖∞ ≤ tol · max(1, ‖dfe‖∞)) and that new_infections(dfe) = 0.

Maps and fixed points

One step of a discrete-time model, the period map of a forced ODE or a year of a daily-step simulation are all maps u ↦ F(u).

DynamicalResilience.map_jacobian — Function
map_jacobian(F, u; method = :forwarddiff, h = 1e-6) -> DiscreteJacobian

The Jacobian of the map u ↦ F(u) at u, as ResilienceCore's DiscreteJacobian with state u. F is any function from a state vector to a state vector of the same length: one step of a discrete-time model, the period map of a forced ODE (period_map_jacobian is this function applied to the flow over one period), or a year of a daily-step simulation. At a fixed point (F(u) = u) its eigenvalues are the multipliers that decide local stability, and ResilienceCore's resilience is the return rate per application of F, −log ρ(∂F/∂u).

  • method = :forwarddiff differentiates F with dual numbers. F must accept them, which rules out code that writes into preallocated Float64 arrays or calls non-Julia libraries.
  • method = :finite_differences uses central differences with step h · max(|u_j|, 1).

u need not be a fixed point; see fixed_point to find one.

DynamicalResilience.fixed_point — Function
fixed_point(F, u0; method = :forwarddiff, h = 1e-6, tol = 1e-9, maxiters = 50)
    -> (u, multipliers, jacobian, converged, iterations)

A fixed point u of the map F (F(u) = u), found by Newton's method from u0: each step solves (F'(u) − I) δ = −(F(u) − u), with F' from map_jacobian (method and h as there). Newton converges to the fixed point near u0 whether it is stable or not.

Returns the point, its multipliers (the eigenvalues of F'(u)), F'(u) as a DiscreteJacobian, whether ‖F(u) − u‖∞ ≤ tol · max(1, ‖u‖∞) was reached, and the number of Newton steps taken. The fixed point is locally stable when every multiplier has modulus below one (isstable(result.jacobian)).

Forced and seasonal systems

DynamicalResilience.period_map_jacobian — Function
period_map_jacobian(prob::ODEProblem, u0, T; alg, t0 = first(prob.tspan), p = prob.p,
                    method = :forwarddiff, h = 1e-6, solve_kwargs...) -> DiscreteJacobian

The Jacobian of the period map Φ_T: u ↦ u(t0 + T) of prob started from u0 at t0, as a DiscreteJacobian (the monodromy matrix of the variational equation). At a point of a T-periodic orbit its eigenvalues are the Floquet multipliers; the orbit is stable when all have modulus below one, and ResilienceCore's resilience of the result is the return rate per period, −log ρ(Φ).

  • alg is the ODE algorithm (required), e.g. Tsit5(); solve_kwargs (such as abstol, reltol) go to solve.
  • method = :forwarddiff differentiates through the solver (forward-mode sensitivities of the integration). This is accurate to solver tolerance and works with the OrdinaryDiffEq solvers when f accepts dual numbers. method = :finite_differences uses central differences with step h · max(|u_j|, 1); use it when f cannot take dual numbers.

This is map_jacobian applied to the period map. u0 is stored as the operator's state. It need not be periodic, but the multipliers mean Floquet multipliers only at a periodic point; see periodic_orbit.

DynamicalResilience.periodic_orbit — Function
periodic_orbit(prob::ODEProblem, u0, T; alg, t0 = first(prob.tspan), p = prob.p,
               method = :forwarddiff, tol = 1e-9, maxiters = 50, solve_kwargs...)
    -> (u, multipliers, jacobian, converged, iterations)

A point u of a T-periodic orbit of prob (a fixed point of the period map, Φ_T(u) = u), found by Newton shooting from u0: each step solves (Φ'(u) − I) δ = −(Φ_T(u) − u), with Φ' from period_map_jacobian; this is fixed_point applied to the period map. For a model with seasonal forcing of period T this is the seasonal attractor or saddle near u0.

Returns the point, its Floquet multipliers (eigenvalues of Φ'(u)), the period-map Jacobian as a DiscreteJacobian, and whether ‖Φ_T(u) − u‖∞ ≤ tol · max(1, ‖u‖∞) was reached.

Thresholds

DynamicalResilience.resilience_along — Function
resilience_along(prob::ODEProblem, set_parameter, values; u0 = prob.u0,
                 metrics = (resilience, reactivity), t = first(prob.tspan),
                 method = :newton, alg = nothing, tol = 1e-10, complex_tol = 1e-8,
                 steady_kwargs...)
    -> (parameter, equilibrium, converged, stable, leading, metrics, transition)

Follow an equilibrium of prob along a parameter and compute resilience metrics on the way: a natural-parameter continuation with warm starts.

For each v in values (in the order given), the parameters are set_parameter(prob.p, v), the equilibrium is found with steady_state from the previous one (from u0 at the start), it is linearised with ResilienceCore's linearise, and each function in metrics is applied to the resulting ContinuousJacobian. Newton's method follows unstable equilibria as well, so the path continues through a Hopf bifurcation; at a fold the equilibrium disappears and Newton stops converging (or jumps to the other branch, whose leading eigenvalue is real and positive).

Returns vectors over values: the equilibria, whether each converged, whether each is stable, the leading_eigenvalue, and a NamedTuple of metric vectors keyed by the metric functions' names (NaN where the equilibrium was not found). transition describes the first loss of stability after a stable stretch, or is nothing:

  • kind = :hopf if the leading eigenvalue at the last stable point is a complex pair (|imag| > complex_tol): a pair crosses the imaginary axis and oscillations appear;
  • kind = :fold if it is real: a real eigenvalue reaches zero, so resilience falls to zero as the equilibrium meets a saddle and disappears;
  • index, the last stable point; estimate, the parameter where the leading real part crosses zero by linear interpolation between the last stable and the next point (or, if the next point did not converge, the midpoint of the two parameter values).

A fold is approached like a square root (resilience ∝ √|v − v*|), so the interpolated estimate is biased towards the last stable point; refine values near the transition for accuracy.

source
DynamicalResilience.leading_eigenvalue — Function
leading_eigenvalue(J::ContinuousJacobian) -> Complex

The eigenvalue of J with the largest real part (of a complex pair, the one with positive imaginary part). Its real part is minus ResilienceCore's resilience.

Uncertainty over parameter draws

DynamicalResilience.metrics_over — Function
metrics_over(build, draws; u0 = nothing, metrics = (resilience, reactivity),
             quantiles = (0.025, 0.5, 0.975), warm_start = true, t = nothing,
             steady_kwargs...)
    -> (equilibrium, converged, stable, metrics, quantiles, probabilities,
        n, n_converged, n_stable, n_unconverged, n_unstable)

Uncertainty in resilience metrics from uncertainty in a model's parameters. For each draw d in draws (any iterable, for example eachrow(coefs) for a matrix of bootstrap coefficients with one replicate per row), build(d) returns a SciML problem (ODEProblem or DiscreteProblem); its equilibrium is found with steady_state, linearised with ResilienceCore's linearise, and each function in metrics is applied to the resulting operator.

  • Starting points. The first draw starts from u0 (prob.u0 if u0 is nothing). With warm_start = true each later draw starts from the last equilibrium found, which is faster and keeps neighbouring draws on the same branch; if that fails, the draw is retried from u0. steady_kwargs (such as method, alg, tol) go to steady_state, and t (default first(prob.tspan)) to both steady_state and linearise.
  • Nothing is dropped. Per-draw vectors cover every draw. Metrics are NaN where no equilibrium converged and are computed for unstable equilibria too (where resilience is negative). The counts n_unconverged and n_unstable say how many draws are in each case.
  • Summaries. quantiles is a NamedTuple of metric quantile vectors at probabilities, taken over the draws with a converged, stable equilibrium only. If no draw is stable, they are NaN.
